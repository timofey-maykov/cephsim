План

  1. ceph orch host maintenance enter host-02 # cephadm сам ставит noout на хост
  2. работы не дольше 3 ч 00 мин
  3. ceph orch host maintenance exit host-02
  4. ceph config set osd osd_max_backfills 2
  5. ждать HEALTH_OK: догон записей за окно ~3.0 TiB, ~57 мин
