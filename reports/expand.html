План

  1. ceph config set osd osd_max_backfills 2
  2. ceph osd set norebalance # чтобы данные не поехали, пока OSD создаются по одному
  3. ceph orch host add new-01 && ceph orch daemon add osd new-01:<устройства> # 12 OSD, класс hdd
  4. ceph orch host add new-02 && ceph orch daemon add osd new-02:<устройства> # 12 OSD, класс hdd
  5. ceph osd unset norebalance
  6. ждать HEALTH_OK (~35 ч 42 мин); затем ceph balancer status
Откуда данные
  • снимок osdmap e3, снят 2026-10-23 22:18 (синтетический)
  • скорость backfill-слота (hdd 40 MB/s, ssd 150 MB/s, nvme 300 MB/s) - значения по умолчанию, без калибровки: время может быть занижено
  • клиентская нагрузка: не учтена
  • раскладка PG считается портом CRUSH; на каждом новом кластере сверяйте её командой cephsim verify
