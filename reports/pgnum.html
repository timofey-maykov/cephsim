План

  1. ceph config set osd osd_max_backfills 2
  2. ceph osd pool set rbd pg_autoscale_mode off # иначе autoscaler вернёт своё значение
  3. ceph osd pool set rbd pg_num 8192 # mgr сам поднимает pgp_num шагами, держа misplaced ≤ target_max_misplaced_ratio (5%)
